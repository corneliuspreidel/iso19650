# 0006 Hash-Routing
Status: angenommen

**Kontext:** GitHub Pages kann Adressen wie `/join/KXQF/3` nicht auf die Startseite umleiten.
**Entscheidung:** Beitritt über `…/#/join/CODE/TEAM`, Beamer über `…/beamer/#/CODE`; Spielleitung unter `/admin/`.
**Folgen:** QR-Codes und Links funktionieren ohne Serverregeln. Der Teil nach `#` wird nicht an Server übertragen (günstig für den Datenschutz).
